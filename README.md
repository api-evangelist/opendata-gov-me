# Montenegro Open Data (opendata-gov-me)

Montenegro Open Data is a national government open-data portal for Montenegro running **CKAN**, exposing a standardized catalog API over ~894 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/opendata-gov-me/refs/heads/main/apis.yml)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.11.0

## API
- **Montenegro Open Data CKAN Action API** — base `https://opendata.gov.me/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://opendata.gov.me)
- Live endpoint verified: `https://opendata.gov.me/api/3/action/status_show`
